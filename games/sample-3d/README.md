# Lawn Gnome Panic

A gnome dodging lawn mowers in 3D, collecting golden acorns across a garden lawn.

Controls: WASD/arrows move, Space jump and double jump, mouse look after clicking the game or Q/E, gamepad supported.

Run with `npm run dev -w games/sample-3d` (http://localhost:5174). Tuning lives in src/config.ts.
