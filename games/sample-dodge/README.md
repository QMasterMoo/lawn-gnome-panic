# Sample Dodge

A small dodge-and-collect arcade game: steer the player, avoid the falling enemies, grab coins for points, and survive as long as you can. It is the reference prototype for this repo, and every graphic and sound is generated in code.

Run it in development:

```
npm run dev -w games/sample-dodge
```

Build it:

```
npm run build -w games/sample-dodge
```

Gameplay tuning (speeds, spawn rates, scoring) lives in `src/config.ts`.
